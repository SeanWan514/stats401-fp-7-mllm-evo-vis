## View the explorer

Use the [published website](https://owen-1234.github.io/mllm-evidence-explorer/) for a demo. For local editing, clone the shared branch and start a static server:

```bash
git clone --branch shilin --single-branch https://github.com/SeanWan514/stats401-fp-7-mllm-evo-vis.git mllm-final-project
cd mllm-final-project
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/final.html`. Do not open the HTML with a `file://` URL: JSON loading requires HTTP. No package installation or API authentication is required for the prepared preview; D3 and fonts use external CDNs. Use another port if 8765 is busy.

## Read the tables without restoring the archive

The Python standard library can read JSON, JSONL and gzip CSV. Run this example from the repository root:

```python
import csv
import gzip
import json
from pathlib import Path

folder = Path("data/final")
model_file = json.loads((folder / "models.json").read_text())
models = {row["id"]: row for row in model_file["models"]}
print("Canonical models:", len(models))

with gzip.open(folder / "feedback.jsonl.gz", "rt", encoding="utf-8") as stream:
    feedback_count = sum(1 for line in stream if line.strip())
print("Feedback records:", feedback_count)

with gzip.open(folder / "benchmark_results.csv.gz", "rt", newline="", encoding="utf-8") as stream:
    measurement_count = sum(1 for row in csv.DictReader(stream))
print("Benchmark measurements:", measurement_count)
```

Expected counts: 57 models, 21,674 feedback records and 143,086 measurements. Iterate JSONL by physical newline; do not split text on every Unicode line separator. The [data dictionary](https://github.com/SeanWan514/stats401-fp-7-mllm-evo-vis/blob/shilin/docs/data-dictionary.md) explains keys and safe aggregation.

## Rebuild the data offline

Requirements: Python 3.10+ and the complete clone. The offline workflow uses no API credentials or third-party Python packages.

On a **fresh clone**, restore the two published archives:

```bash
python3 scripts/restore_public_data.py
```

The helper verifies hashes, restores all 1,861 raw-cache files and the full feedback JSONL, and refuses to overwrite different local originals. If you already have the original research caches, skip restoration. For a separate inspection copy, use `python3 scripts/restore_public_data.py --destination /path/to/empty-folder`; processing scripts still read the repository's own `data/raw/`.

Rebuild in dependency order:

```bash
python3 scripts/collect_repositories.py --process
python3 scripts/build_final_models.py
python3 scripts/process_feedback.py
python3 scripts/build_final_views.py
python3 scripts/validate_final_data.py
```

Or use `make rebuild` after restoration. This overwrites generated outputs and reports; save work in versioned source/configuration changes rather than direct edits to generated JSON.

A first public rebuild can change content hashes relative to the original local snapshot because public copies mask credential-like strings. All records remain included. After that initial rebuild, check repeatability:

```bash
python3 scripts/verify_offline_rebuild.py
```

The check rebuilds again and compares all eight output files byte-for-byte. It requires the decompressed benchmark CSV generated by the model build; it is not a fresh-clone preview command.

## Run checks and build the website

```bash
python3 -m unittest discover -s tests -v
python3 scripts/test_feedback_processing.py
node --check final.js
python3 scripts/build_static_site.py
```

The Python commands run 31 regression checks. Node is needed only for the JavaScript syntax check. The static build writes `dist/` using an explicit allowlist; it excludes the full feedback and raw archive from automatic browser downloads. Serving `dist/` preserves the interim page at its root; open `final.html` for the final explorer.

## Troubleshooting

| Symptom | Action |
| --- | --- |
| The browser cannot load JSON | Use HTTP and open `final.html`; check the server's working directory |
| Charts do not appear | Check access to the D3 CDN and the browser console |
| Port already in use | Choose another port, such as 8766 |
| Missing `data/raw/` during rebuild | Restore the archives in this repository first |
| Restore refuses an existing file | Keep the original; skip restore or choose a separate empty destination |
| Validator cannot find `feedback.jsonl` | Restore it, or run the feedback processor after restoring raw caches |
| Benchmark CSV is missing | Read the gzip directly for analysis, or run the model build for a decompressed CSV |
| Generated files change after a first public rebuild | Review the public-copy/redaction note, then check a second identical rebuild |

Online recollection is a separate workflow. Use the [pipeline guide](https://github.com/SeanWan514/stats401-fp-7-mllm-evo-vis/blob/shilin/docs/data-pipeline.md) for dependencies, source APIs and cache-snapshot rules.
